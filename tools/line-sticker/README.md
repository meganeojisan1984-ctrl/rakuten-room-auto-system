# LINE アニメーションスタンプ ビルダー

グリーンバックのモーション動画から、LINE Creators Market の申請用
アニメーションスタンプ（APNG）一式を生成する。

## 出力規格

| 項目 | 値 |
| --- | --- |
| 形式 | APNG（拡張子 `.png`） |
| サイズ | 320 × 270 px |
| 余白 | 全辺 10px 以上 |
| フレーム数 | 5〜20（実績 16〜20） |
| 再生時間 | 2.000 秒ちょうど（ループ無限） |
| ファイルサイズ | 1 ファイル 300KB 以下 |
| 背景 | 完全透過（内部に透過穴なし） |
| 申請 zip | `main.png`(240×240 APNG) + `tab.png`(96×74 透過PNG) + `01.png`〜`NN.png` |

## 使い方

```bash
pip install numpy pillow scipy imageio-ffmpeg   # ffmpeg 実体は imageio-ffmpeg 同梱でよい

# 1. カット定義（動画・開始フレーム・フレーム数）を JSON で用意する
# 2. 候補を一括生成
python3 tools/line-sticker/build.py --plan cuts.json --out candidates/

# 3. 規格チェック（全項目を機械的に検証）
python3 tools/line-sticker/verify.py "candidates/*.png"

# 4. 採用分を選んで申請 zip を組み立て
python3 tools/line-sticker/pack.py \
  --plan cuts.json --cand candidates/ --out set24/ \
  --hero c06_v13_180 --tab c09_v13_288 \
  --select "c01_v13_000,c02_v13_036,..."
```

## 構成

- `keying.py` — グリーンバックのキーイング。背景色をフレーム外周から実測し、
  緑度で線形にアルファを求めたうえで背景色に対してアンプリマルチプライするため、
  アンチエイリアス部に緑の縁が残らない。
- `apng.py` — APNG エンコーダ。`fcTL` の `delay_num/delay_den` を分数で書けるので
  再生時間を 1/2/3/4 秒ちょうどに合わせられる。2 フレーム目以降は前フレームとの
  差分矩形だけを書き出してサイズを抑える。
- `build.py` — 切り出し → キーイング → 320×270 配置 → 減色 → APNG 出力。
  300KB を超える場合は「フレーム数 → 色数」の順に品質ラダーを降りる。
- `pack.py` — `main.png` / `tab.png` / 連番 + zip の組み立て。
- `verify.py` — 出力が上表の全項目を満たすか検証する。

## 「イラスト内部が透過されています」対策

過去のリジェクト理由。原因になりうる箇所を 3 段階で塞いでいる。

1. **キーイング直後** — `seal_interior()` が、不透明な絵柄に囲まれていて
   画面外へ到達できない領域（＝内部の穴）をすべて不透明化する。
   シルエット外周のアンチエイリアスは連続領域として画面端につながるため、
   誤って潰さずに残る。
2. **リサイズ後** — 320×270 に縮小した後にもう一度同じ処理を掛ける。
3. **減色後** — ここが見落としやすい。パレット化でアルファ 255 の画素が
   半透明パレットに吸われると 1〜7px の不可視の穴が再発する。
   `quantise()` は完全不透明な画素を不透明パレットのみに割り当て、
   さらに書き出す直前のインデックス画像に対して穴チェックと修復を行う。

`verify.py` が全フレームを走査して残存を検出するので、申請前に必ず通すこと。
