# 商品起点のInstagram画像クリエイティブ設計

## 目的

楽天ROOM掲載商品の情報を分析し、商品と使い方・説明が一致する5枚のInstagramカルーセルを作る。現在の「背景画像を先に生成し、後から事務的な文字を重ねる」流れを、次の一貫した流れへ変更する。

1. 商品分析
2. 情報整理
3. スライド企画
4. 文字入り画像プロンプト化
5. 画像作成・合成
6. 商品との整合性検証

参考URLは固定テンプレートとしてコピーせず、淡色背景、カード、手書き風の線・矢印、余白を活かした視認性の高い編集方向として扱う。

## 要件

### 商品分析

商品名、商品説明、カテゴリ、価格、レビュー、商品画像を根拠として、次を構造化する。

- 商品の正確な呼称
- 商品カテゴリ
- 商品説明から確認できる特徴
- 明記された用途・使用場面
- サイズ情報の有無と重要度
- 見せるべき購入判断材料
- 商品情報にないため言ってはいけない表現

美容品、美容家電、キャンプ用品、食品、収納用品など、カテゴリと商品説明に応じて企画を切り替える。サイズ情報が明記され、設置・携帯・収納判断に影響する場合は寸法や比較スケールを採用する。サイズが確認できない場合は、寸法を推測せず、使用シーン、操作、質感、収納性などの確認できる軸へ切り替える。

### 5枚のスライド企画

5枚は商品ごとに次の基本役割を持つ。ただし、②は固定文言ではなく `slideType` の選択結果で差し替える。

1. フック：誰のどんな場面に合うかを一瞬で示す
2. 商品理解：サイズ比較、特徴の見える化、使用準備、素材・質感などから最適なものを選ぶ
3. 使い方：商品説明に根拠がある具体的な使う場面・手順を見せる
4. 購入判断：価格、レビュー、仕様、セット内容など確認可能な根拠を整理する
5. ROOM導線：プロフィール、楽天ROOM、リンク風カード、矢印などで次の行動を明確にする

各スライド企画には、役割、目的、採用コピー、補足コピー、被写体、構図、色、装飾、文字配置、商品画像配置、禁止事項を含める。コピーは商品分析で確認できる事実と用途から生成し、効果・体験・ランキング・割引を推測しない。

### 文字入りプロンプト

画像生成プロンプトは背景だけを依頼する文章ではなく、以下を明示する完成イメージ指示にする。

- 正方形1080×1080のInstagram投稿
- 主見出しをそのまま記載
- 補足文・ラベル・数値・矢印・アイコンの内容
- 日本語文字の大きさ、太さ、手書き風/明朝/ゴシック等の使い分け
- 文字の位置、余白、視線誘導
- 商品写真の位置と大きさ
- 商品カテゴリに応じた背景・小物
- 誤認防止の禁止事項

AIに文字を描かせる場合の誤字リスクを下げるため、生成用の `prompt` と、レンダラーで同じ文言を再現する `overlayCopy` を企画結果に保持する。元画像を正確に見せる必要がある商品写真、価格、レビュー、ROOM URL相当の導線は合成側で保持する。これにより、文字入りプロンプトによるインパクトと、商品情報の正確性を両立する。

### ②の切り替えルール

- 寸法・容量・設置幅が商品説明にあり、購入判断に関係する商品：`size_visual`
- 美容品・美容家電で使用部位や手順が説明されている商品：`beauty_use`
- キャンプ用品で設営、携帯、収納、使用環境が説明されている商品：`camp_use`
- 食品・飲料で食べる場面や保存方法が説明されている商品：`food_scene`
- 収納・生活用品で置き場所や整理対象が説明されている商品：`storage_use`
- 上記以外：`feature_visual`

サイズ情報がない商品に寸法線、定規、人物との比較を生成させない。逆に寸法がある商品では、商品を別物に置き換えない範囲で寸法ラベルと自然な比較対象を提案する。

## データフロー

`RakutenItem` → `ProductAnalysis` → `ImageCreativePlan[5]` → `SlidePrompt[5]` → AI背景/文字入り画像 → 既存カルーセル合成 → 検証

既存の `SalesStrategyBrief` は販売戦略の共通情報として再利用する。画像企画は販売戦略の `problem`、`solution`、`imageScene`、`imageComment` を受け取るが、画像固有の判断（②の切り替え、文字、装飾、レイアウト）は新しい画像企画層で行う。

## エラー処理

- 商品説明が空または短い場合は、商品名とカテゴリに基づく保守的な企画へフォールバックする。
- サイズが推測になりそうな場合は `feature_visual` または使用シーンへ切り替える。
- AI応答が5枚未満の場合は既存の失敗処理で投稿を止める。
- 文字入りプロンプトの生成に失敗した場合は、商品事実から決定的に作る簡易企画へフォールバックする。
- プロンプトに価格・レビュー・ROOM導線の事実が混在しても、最終レンダラーでは商品データを正とする。

## テスト

- 美容品、美容家電、キャンプ用品、サイズあり商品、サイズ情報なし商品で②の `slideType` が期待どおり切り替わる。
- 商品説明にない寸法・効果・レビュー内容を企画やプロンプトが生成しない。
- 各スライドに主見出し、補足、文字配置、装飾、商品との関係が含まれる。
- 5枚の役割が重複せず、②が商品タイプに対応する。
- AI生成へ渡すプロンプトが「文字なし背景」だけの旧形式に戻っていない。
- 既存の5枚カルーセル生成・投稿・公開テストが通る。
