# SNS商品紹介クリエイティブ 基本プロンプト

この資料は、楽天ROOM向けSNS商品紹介画像を作成するときの共通ルールです。
参考画像はレイアウト・雰囲気の参考にのみ使い、商品名・価格・レビュー・仕様・機能は必ず選定された楽天商品データを正とします。

## 目的

選定カテゴリに合った商品を、SNSで保存・閲覧・楽天ROOMへの遷移につながる5ページのカルーセルで紹介する。

## 商品選定ルール

- 商品は現在選択されているカテゴリから選ぶ。
- カテゴリ外の商品を混ぜない。
- 商品名、商品説明、価格、レビュー、商品画像を商品情報の根拠とする。
- 商品情報にない効果、性能、寸法、素材、ランキング、割引条件を追加しない。
- 価格は固定値を使わず、選定商品の実際の販売価格を表示する。
- 通常価格・セール価格を表示する場合は、商品データに両方がある場合だけ表示する。

## 5ページの役割

### 1ページ目：興味喚起

- 目的：ターゲットの悩みや関心を一瞬で伝える。
- 表示文字：短い悩みの見出し、商品カテゴリ、商品名の短縮表記。
- 構図：生活シーンの中で商品を主役にする。見出しと商品を重ねない。

### 2ページ目：商品理解

- 目的：そのカテゴリの商品として、購入前に見るべき特徴を伝える。
- 表示文字：商品説明から確認できる代表的な特徴を1〜2個。
- 構図：商品本体を大きく見せ、特徴の説明は周囲のカードや吹き出しに分ける。

### 3ページ目：使う場面・使い方

- 目的：購入後の使用場面を具体的に想像してもらう。
- 表示文字：商品説明に根拠のある使い方、使用場所、手順。
- 構図：カテゴリに合った自然な生活シーン。根拠のないビフォーアフターや効果を作らない。

### 4ページ目：価格・レビュー・購入前確認

- 目的：購入判断に必要な情報を整理する。
- 表示文字：販売価格、レビュー評価、レビュー件数、購入前に確認したい条件。
- 構図：価格とレビューは独立した読みやすいカードにする。商品画像や他の文字と重ねない。

### 5ページ目：楽天ROOMへの導線

- 目的：商品ページまたは楽天ROOMへ自然に誘導する。
- 表示文字：「気になったらプロフィールの楽天ROOMへ」などの導線文。
- 構図：商品を小さく添え、リンク風カード・矢印・保存を促す短い文を配置する。
- 実在しないURL、存在しないキャンペーン、誤った価格は描画しない。

## ビジュアル方針

- 参考画像のような、淡い生活空間・自然光・商品中心の構成。
- 手書き風の見出し、マーカー線、囲み、矢印、吹き出しを適度に使う。
- 背景はカテゴリに合わせて変える。美容品なら洗面台、食品なら食卓、アウトドア用品なら屋外など。
- 商品画像ゾーン、文字ゾーン、CTAゾーンを最初に分ける。
- 文字と商品画像を重ねない。
- 1ページの主張は1つに絞り、長文を詰め込まない。
- 小さな商品カードを多用せず、紹介対象の商品を明確にする。

## 画像生成プロンプトに必ず含める情報

各ページのプロンプトには、次の項目を明記する。

```text
カテゴリ：<選定カテゴリ>
商品名：<商品データの正式名称>
ページ役割：<5ページの役割>
表示する見出し：<確定した日本語>
表示する補足文：<確定した日本語>
表示する価格・レビュー：<商品データにある場合のみ>
商品画像の位置：<例：中央右、文字と分離>
文字ゾーン：<例：上部左、商品と重ならない>
背景・使用場面：<商品カテゴリと商品説明に合う場面>
禁止事項：<商品情報にない主張、誤った価格、文字と商品の重なりなど>
```

## 参考画像の扱い

生成時は `docs/creative/references/` 内の画像を必ず参照入力として読み込み、色、構図、文字の雰囲気、装飾、余白、情報量の参考にする。
フォルダ内に複数の参考画像がある場合は、可能な限りすべてを確認し、共通するデザイン要素を採用する。参考画像を見ずに文章だけからレイアウトを作らない。
参考画像に書かれた別商品の商品名・価格・機能・レビューは、新しい商品の情報として流用しない。

## AI画像生成用：全カテゴリ対応5ページテンプレート

以下の前提とページ別指示を、商品ごとに実データで置き換えてAI画像生成プロンプトへ渡す。

### 前提指示

以下の要素をベースに、SNSスワイプ投稿用の画像を生成する。

- ターゲット層：`[女性 or 男性]`向け
- デザインテイスト：女性向けは「淡いトーン、柔らかい光、手書き風の装飾」、男性向けは「スタイリッシュ、コントラスト強め、シャープなフォントと直線的な装飾」
- 商品：`[カテゴリ名]`の`[商品名]`
- 商品名、機能、価格、レビュー、サイズ、保証、使用方法は、渡された商品データに存在する内容だけを使用する
- 商品画像ゾーンと文字ゾーンを明確に分離し、文字を商品画像に重ねない
- 参考画像は構図・雰囲気・装飾の参考にし、別商品の情報を流用しない
- `docs/creative/references/` 内の参考画像を必ず読み込み、共通するレイアウトの特徴を反映する

### 1ページ目：興味喚起

- カテゴリ：`[カテゴリ名]`
- 商品名：`[商品名]`
- ページ役割：興味喚起
- 表示する見出し：`[商品データに根拠のあるターゲットの悩みに刺さる短い見出し]`
- 表示する補足文：`[一言のサブタイトル]`
- 商品画像の位置：中央右、文字と分離
- 文字ゾーン：左上部から中央にかけて大きく配置
- 背景・使用場面：`[商品の使用シーンに合う背景]`
- 禁止事項：見出しと商品を重ねない、長文を入れない、過剰な装飾を避ける、根拠のない効果を断定しない

### 2ページ目：商品理解

- カテゴリ：`[カテゴリ名]`
- 商品名：`[商品名]`
- ページ役割：商品理解
- 表示する見出し：`[商品説明で確認できる最大の特徴を1つ]`
- 表示する補足文：`[その特徴を支える確認済みの機能・仕様・成分など]`
- 商品画像の位置：中央に大きく配置
- 文字ゾーン：商品の周囲にカードや吹き出しで配置。男性向けはソリッドな枠を使う
- 背景・使用場面：`[商品を際立たせるシンプルな背景]`
- 禁止事項：文字と商品画像を重ねない、特徴を詰め込みすぎない、商品説明にない特徴を作らない

### 3ページ目：使う場面・使い方

- カテゴリ：`[カテゴリ名]`
- 商品名：`[商品名]`
- ページ役割：使う場面・使い方
- 表示する見出し：`[商品説明に根拠のある日常への取り入れやすさ]`
- 表示する補足文：`[確認済みの使用手順やシーンを短く]`
- 商品画像の位置：下部またはシーンの一部として自然に配置
- 文字ゾーン：上部に見出し、中央に手順やシーンの補足
- 背景・使用場面：`[ターゲットが実際の使用を想像できる生活空間や風景]`
- 禁止事項：嘘のビフォーアフターを作らない、複雑な人物描写を避ける、未確認の使用方法を追加しない

### 4ページ目：価格・レビュー・購入前確認

- カテゴリ：`[カテゴリ名]`
- 商品名：`[商品名]`
- ページ役割：価格・レビュー・購入前確認
- 表示する見出し：購入前のチェックポイント
- 表示する補足文：`[商品データにある仕様・サイズ・保証・対応条件など]`
- 表示する価格・レビュー：`[実際の販売価格と★評価・レビュー件数。データがある場合のみ]`
- 商品画像の位置：右下に小さく配置
- 文字ゾーン：中央に独立した読みやすい情報カードとして配置
- 背景・使用場面：情報に集中させるための無地に近いシンプルな背景
- 禁止事項：価格やレビューを他の要素と重ねない、誤った数値を生成しない、存在しない保証・サイズを追加しない

### 5ページ目：楽天ROOMへの導線

- カテゴリ：`[カテゴリ名]`
- 商品名：`[商品名]`
- ページ役割：楽天ROOMへの導線
- 表示する見出し：ここからチェック！
- 表示する補足文：気になる商品はプロフィールの楽天ROOMにまとめています
- 商品画像の位置：左下に小さく添える
- 文字ゾーン：中央にリンク風カード、右下に「保存」を促すアイコンと短い文
- 背景・使用場面：1ページ目のトーンに合わせたシンプルな背景
- 禁止事項：実在しないURLを書き込まない、文字化けを防ぐためテキストは最小限にする、商品ページにないキャンペーンを表示しない

### 生成時の最終指示

指定された表示文字を省略・改変・別商品向けに置換しない。日本語文字は読みやすく、商品画像と重ならない位置に配置する。ページごとの役割を混ぜず、5ページ全体で「興味喚起 → 商品理解 → 使用イメージ → 購入判断 → 楽天ROOM導線」の流れを作る。

## 最終確認

- 商品画像と紹介文の商品が同じか。
- カテゴリと商品が一致しているか。
- 価格とレビューが商品データと一致しているか。
- 各ページの役割が重複していないか。
- 文字と商品画像が重なっていないか。
- 生成された文字に誤字・欠落・別商品の文言がないか。
