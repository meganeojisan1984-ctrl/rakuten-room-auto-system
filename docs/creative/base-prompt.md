# SNS商品紹介クリエイティブ 基本ルール

Instagramカルーセル用の画像は、`src/ig/image-creative.ts`（ページ設計）と `src/ig/ai-image.ts`（生成プロンプト）で自動生成します。
このページは、その実装が従うルールをまとめたものです。

## 5ページの構成

| ページ | 構成 |
| --- | --- |
| 1 表紙 | 問いかけの一文 → 大きなコピー、商品を大きく、アイコン付きチップ4個、締めの一文 |
| 2 機能まとめ | リボン帯の見出し、商品＋機能カード3枚、「こんな方におすすめ」チェックリスト |
| 3 利用シーン | 見出し＋補足、商品、生活シーンの写真カード3枚 |
| 4 価格・評価 | 楽天の実データ（価格・レビュー平均・件数）だけをバッジとカードで表示 |
| 5 ROOM導線 | リンク風カード、スマホの簡略イラスト、3項目、タップを示す指アイコン |

## デザインテーマ

商品カテゴリで自動選択します。

- 家電・ガジェット・アウトドア：ダーク×ゴールド
- ベビー・キッズ：パステル
- 美容・ダイエット・その他：ベージュ×ローズ

## 守ること

- 画像生成に渡す画像は、紹介する商品の写真1枚だけ。別商品が写った見本画像は渡さない（生成画像に別商品が混入するため）。
- 画像内の文字は確定テキストのみ。短いコピーは低コストのテキストモデルで生成し、商品データにない数値や誇大表現は検証で除外する。
- 口コミ・体験談・年代性別ラベル・アカウント名・フォロワー数は創作しない（実データのレビュー平均と件数のみ表示）。
- 配送・設置・注文条件の文章や、商品名に含まれる管理コードは画像のコピーに使わない。
- 生成後に「別の商品が描かれていないか」「価格表記が正しいか」を自動検品し、不合格なら投稿しない。
- AI画像を用意できない回は Instagram への投稿を見送る。別デザインの画像には切り替えない。
