# LINE アニメーションスタンプ 申請素材（24個セット）

`tools/line-sticker/` のパイプラインで、グリーンバックのモーション動画
5 本から生成したもの。

## 中身

- `line-sticker-set24.zip` — **申請用 zip**。中身は `main.png` / `tab.png` /
  `01.png`〜`24.png` のフラット構成（LINE Creators Market の要求どおり）。
- `set24/` — zip と同じ内容を展開したもの。`manifest.json` に採用カットの対応表。
- `cuts.json` — 全 29 候補のカット定義（元動画・開始フレーム・フレーム数）。
- `candidates-report.json` — 候補 29 個それぞれの出力諸元。

## 規格

全 24 ファイルが以下を満たす（`tools/line-sticker/verify.py` で検証済み）。

- APNG / 320 × 270 px / 全辺 10px 以上の余白
- 16〜20 フレーム、ループ再生 **2.000 秒ちょうど**、ループ回数 無限
- 83.6KB〜298.4KB（上限 300KB 以下）
- 背景 完全透過、**絵柄内部の透過穴 0 件**

`main.png` は 240×240 の APNG（20 フレーム / 2.000 秒 / 210.8KB）、
`tab.png` は 96×74 の静止透過 PNG。

## 元動画と採用区間

元動画は 24fps・15.08 秒。グリーンバックが有効な区間だけを使用している。

| 元ファイル | 使用区間（フレーム） | 備考 |
| --- | --- | --- |
| `sticker_00013` | 0–361（全編） | |
| `sticker_00014` | 120–219 | それ以外は室内背景のため不使用 |
| `sticker_00015` | 0–361（全編） | |
| `sticker_00018` | なし | ほぼ全編がレンガ壁の背景で使用不可 |
| `sticker_00019` | 0–144 / 176–237 / 249–328 | |

1 カット = 36 フレーム（1.5 秒）。これを 20 フレームに間引き、
1 フレーム 1/10 秒で再生することでループを 2.000 秒ちょうどに合わせている。
