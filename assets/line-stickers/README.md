# LINE アニメーションスタンプ 申請素材（24個セット）

`tools/line-sticker/` のパイプラインで、グリーンバックのモーション動画
5 本から生成したもの。

## 中身

- `line-sticker-set24.zip` — **申請用 zip**。中身は `main.png` / `tab.png` /
  `01.png`〜`24.png` のフラット構成（LINE Creators Market の要求どおり）。
- `set24/` — zip と同じ内容を展開したもの。`manifest.json` に採用カットの対応表。
- `cuts.json` — 全 29 候補のカット定義（元動画・開始フレーム・フレーム数）。
- `candidates-report.json` — 候補 29 個それぞれの出力諸元。

## 規格

全 24 ファイルが以下を満たす（`tools/line-sticker/verify.py` で検証済み）。

- APNG / **カラーモード RGB（colour type 6）** / 320 × 270 px / 全辺 10px 以上の余白
- 16〜20 フレーム、1 ループ **2.000 秒ちょうど** × **2 回** = 合計 4.000 秒
- 192.1KB〜689.1KB（LINE の上限は 1 ファイル 1MB）
- 背景 完全透過、**絵柄内部の透過穴 0 件**

`main.png` は 240×240 の APNG（20 フレーム / 2.000 秒 × 2 / 459.2KB）、
`tab.png` は 96×74 の静止透過 PNG。zip 合計 13.45MB（上限 60MB）。

### 申請時にエラーになった原因（対応済み）

初回は `tab.png` 以外の全ファイルがアップロード時にエラーになった。
公式ガイドラインと突き合わせて 2 点の違反が判明している。

1. **カラーモード** — 300KB に収めるためインデックスカラー（colour type 3）で
   書き出していた。ガイドラインの指定は RGB。減色自体は続けたうえで、
   書き出しを true-colour RGBA に変更した（`apng.py` は colour type 6 固定）。
2. **ループ回数** — 無限ループ（`acTL` の `num_plays` = 0）で書き出していた。
   指定は 1 スタンプあたり 1〜4 回。2.000 秒 × 2 回 = 合計 4.000 秒とした。

`verify.py` は両方を検査項目に追加済み。
